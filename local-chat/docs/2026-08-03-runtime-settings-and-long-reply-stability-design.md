# Qwen Local 运行参数设置与长回复稳定性设计

## 目标

- 将用户可理解、可安全修改的生成、上下文、模型、MemOS 和服务参数集中到窗口内设置面板。
- 为每项参数提供经过验证的默认值，并支持一键恢复默认值。
- 区分立即生效参数与模型重启后生效参数。
- 去掉固定 `max_tokens = 1024` 和按 Unicode 字符裁剪上下文的做法。
- 修复长回复完成时的界面卡退，并保留用户问题在视口中的位置。

## 上下文预算

发送上下文时从最新完整对话轮次向前选择。预算使用 Token 估算，不再使用固定 6,000 字符：

`输入预算 = 上下文窗口 - 最大输出 - 安全余量`

安全余量默认取上下文窗口的约 5%，最少 256 Token。始终保留系统提示、当前问题和一次性 MemOS 上下文；超出预算时只移除最旧的完整问答轮次。本次最大输出还会按剩余上下文动态缩减。

## 界面与生效规则

主界面底部增加“设置”按钮，打开固定在同一视觉树中的右侧设置面板。使用原生 `NumberBox`、`TextBox`、`ToggleSwitch` 和分组标题，保持当前视觉基线。输入非法值时不保存并给出字段级错误。

实际重复打开 `ContentDialog` 时复现了 `Microsoft.UI.Xaml.dll` 原生访问冲突，因此设置不再依赖 Popup/ContentDialog 的脱离与重挂生命周期。固定面板只切换可见性，既保留原生控件，也减少一次弹出层视觉树和焦点所有权转换。

设置面板内部的 `NumberBox` 统一使用内嵌微调按钮，不使用会另外创建 Popup 的 `Compact` 模式；打开面板时也不强制聚焦数值框。这样关闭面板或转移焦点时没有临时微调弹层需要从视觉树分离。

设置面板关闭时先把焦点交还主界面的设置按钮，下一次 UI 调度再禁用面板交互并把透明度设为零。面板永久留在视觉树中，不使用 `Collapsed` 拆除整棵设置控件子树，从结构上避开延迟焦点、选择和模板事件访问已卸载元素。

“恢复默认值”只重填弹窗中的默认参数，用户点击“保存”后才写入磁盘。生成参数立即生效；模型启动参数保存后标记为“重启模型后生效”。共享服务不是当前窗口所有时，不强制结束它。

## 长回复稳定性

当前回复完成路径会把富文本加入虚拟列表后，立即强制 `UpdateLayout` 并再次 `ScrollIntoView`。最新系统事件记录为 `Microsoft.UI.Xaml.dll` 原生访问冲突。实现将取消回复后的二次定位和所有强制同步布局：问题发送后只定位一次，回复追加不改变视口，依靠原生布局完成呈现。

流式显示按稳定节奏合并文本更新，避免为每个 Token 重建 Markdown 树；完成后只做一次完整 Markdown 呈现。若服务以 `finish_reason=length` 结束，界面明确提示达到输出上限。

流式回复建立后先把本轮问题定位一次；回复完成并切换到 Markdown 显示后，再异步把同一个问题定位一次。期间不调用 `UpdateLayout`，也不按 Token 修正滚动位置。完成后的复制按钮因此回到问题下方的回复标题处，用户仍可自由滚动和选择正文。

窗口关闭不再从 Page 的 `Unloaded` 事件启动 `async void` 清理。原生关闭事件先取消本次关闭，让视觉树保持有效；等待日志队列、MemOS 客户端和本窗口持有的资源完成清理后，再放行一次最终关闭，避免异步清理跨越 XAML 拆树阶段。

## 验证

- 默认值、旧设置迁移、保存/重新加载和恢复默认值。
- 参数范围验证、动态输出预算和完整轮次裁剪。
- 请求 JSON 使用当前设置，并解析 `finish_reason`。
- 长 Markdown 数据和连续多次回复不会走强制同步布局路径。
- 构建、发布后从实际桌面入口启动，验证设置持久化、重置、长回复和共享模型不被错误结束。
