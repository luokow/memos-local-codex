# Qwen 本地聊天视觉刷新设计

## 1. 设计结论

采用用户选定的 `3C · 粒子光带` 方向：深黑玻璃层次、斜向柔光、稀疏星点和少量星图连线。界面固定使用黑白主题，不增加主题切换，也不引入第三方图片、字体、WebView 或联网资源。

本次刷新只改变窗口视觉、布局和图标，不改变 Qwen、MemOS、日志、设置持久化、模型复用、进程所有权和回环网络行为。

## 2. 目标

- 让本地聊天窗口具有简约、克制、可长期使用的科技感。
- 让模型、记忆和日志状态在一眼可读的同时保持低视觉噪声。
- 为 EXE、窗口标题栏、任务栏和资源管理器提供统一的黑白应用图标。
- 保留现有中文输入、多轮对话、文本选择、键盘快捷键和无障碍名称。
- 在 `760 × 560` 最小窗口和高 DPI 显示器上保持内容可用。

## 3. 非目标

- 不实现透明窗口、亚克力材质、窗口穿透或系统级主题跟随。
- 不把 WinForms 改成 WebView、WPF、WinUI 或浏览器应用。
- 不添加动画粒子、持续 GPU 绘制、声音或联网素材。
- 不改变聊天消息格式、上下文预算或记忆召回逻辑。
- 不增加侧边栏、会话列表、文件上传、模型切换或新的设置项。

## 4. 视觉语言

### 4.1 色彩

只使用中性灰阶：

| 角色 | 建议颜色 |
| --- | --- |
| 窗口背景 | `#080809` |
| 顶栏 | `#111112` → `#1A1A1C` |
| 主内容面板 | `#0E0E0F` |
| 次级面板 | `#18181A` |
| 主文字 | `#F1F1EE` |
| 次级文字 | `#A3A3A0` |
| 弱文字 | `#6F6F6C` |
| 边框 | `#353537` |
| 高亮按钮 | `#F0F0ED`，文字 `#111111` |

运行状态不只依赖颜色。正常、关闭、处理中、警告和错误分别使用实心点、空心点、短横线、三角标记和叉号，并配合明确文字。为了保持黑白主题，不使用蓝色主按钮、绿色成功色或红色错误色。

### 4.2 字体

- 中文和正文：`Microsoft YaHei UI`。
- 状态、端口、模型和短标签：`Cascadia Mono`，不可用时回退 `Consolas`。
- 标题使用 11–12pt 半粗体；正文 10–10.5pt；微标签 8–8.5pt。
- 不下载或打包外部字体。

### 4.3 形状

- 主面板圆角视觉半径约 14–16px。
- 输入框和消息区边框使用 1px 中灰线。
- 主按钮圆角约 9–10px；次级按钮使用深色底和细边框。
- 不使用大面积阴影；只在主面板和弹出提示使用低透明度软阴影。

## 5. 粒子光带装饰

装饰由 WinForms/GDI+ 原生绘制，使用固定坐标和窗口尺寸计算，不使用随机动画：

- 一条从左下向右上的宽柔光带，位于窗口右侧约 35% 区域。
- 6–10 个固定星点，直径 1–2px，亮度分三级。
- 2–3 条极细星图连线，只连接右上区域的节点。
- 右上角保留一个短坐标微标签，例如 `LOCAL / 18135`。
- 装饰对比度低于边框，不覆盖输入文字、聊天文字或开关标签。
- 窗口宽度低于 820px 时隐藏星图连线，只保留柔光和 4 个星点。
- 窗口失焦、忙碌或生成回答时不做闪烁和运动。

WinForms 标准控件不支持网页式真实背景模糊。本实现使用多层纯色、线性渐变和半透明绘制近似玻璃层次，不宣称系统级玻璃效果。

## 6. 应用图标

图标使用代码原生矢量设计，并保持通用聊天工具语义：

- 外形为黑色圆角方形。
- 中心是白色对话气泡，气泡内放置三个黑色消息点。
- 不使用 `Q`、模型名称或厂商品牌标记，使图标可用于通用本地聊天工具。
- 16px 尺寸保留黑色外形、白色气泡和三个消息点。
- 32px 及以上使用更平滑的圆角和气泡尾部。

交付资源：

```text
src/QwenLocalChat/Assets/qwen-local-chat-icon.svg
src/QwenLocalChat/Assets/qwen-local-chat.ico
```

ICO 包含 `16、20、24、32、48、64、128、256px` 图层。项目通过 `ApplicationIcon` 嵌入 EXE，窗口运行时使用同一图标，确保资源管理器、标题栏和任务栏一致。

## 7. 窗口布局

```text
┌ 图标  Qwen Local / LOCAL CORE ─── ● 9B  ○ 记忆  ○ 日志 ┐
│ 本地状态与错误提示                                      │
│ ┌──────────────── 对话记录 ──────────────────────────┐ │
│ │  低亮度斜向光带 · 稀疏星点 · 正文保持最高对比度     │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌ 输入消息 ──────────────────────────────────── [发送] ┐ │
│  □ MemOS  □ 保存日志       清空会话  打开日志目录       │
└─────────────────────────────────────────────────────────┘
```

### 7.1 顶栏

- 左侧：应用图标、`Qwen Local`、小型 `LOCAL CORE` 标签。
- 右侧：模型、MemOS、日志三项状态。
- 状态示例：`● 9B 就绪`、`○ 记忆关闭`、`○ 日志关闭`。
- 当前 `_notice` 放在顶栏下沿，以单行弱文字显示本地状态、错误或数据位置。

### 7.2 对话区

- 保留只读 `RichTextBox`，确保选择、复制、滚动和无障碍行为不退化。
- 背景改为近黑，边框改为深灰，正文使用浅灰。
- 系统消息使用 `SYSTEM` 微标签和弱灰文字。
- 用户、Qwen 标题使用不同的灰阶字重，不依赖彩色区分。
- 每轮消息增加垂直留白和细分隔，不实现会损害文本选择的复杂气泡控件。
- 粒子光带绘制在外层背景和对话区右侧留白，不直接覆盖 RichTextBox 文字。

### 7.3 输入区

- 输入框置于深灰圆角容器，保持多行、滚动条和 `Shift+Enter` 行为。
- 右侧主按钮改为白底黑字或黑色箭头图标，文字保留为 `发送`，生成时显示 `生成中…`。
- 输入框下方保留快捷键提示：`Enter 发送 · Shift+Enter 换行`。

### 7.4 设置与操作

- `使用 MemOS 长期记忆`和`保存聊天日志`保留为可直接操作的复选框。
- 两个开关首次启动仍关闭，之后继续记住用户选择。
- `清空会话`、`打开日志目录`使用深色次级按钮。
- 操作栏按“设置在左、会话操作在右”排列；窗口变窄时允许换行或压缩间距，不隐藏功能。

## 8. 原生实现结构

在 `QwenLocalChat` 项目内增加小型视觉组件，不引入 NuGet 包：

- `ThemePalette.cs`：集中保存黑白主题颜色、字体和间距。
- `ObsidianBackdropPanel.cs`：双缓冲绘制渐变、柔光、星点和星图连线。
- `RoundedPanel.cs`：为输入区和主内容区绘制圆角边框。
- `IconAssets`：保存 SVG 源文件和由构建前固定脚本生成的 ICO。

`MainForm` 继续负责现有事件和业务状态，只重组 `BuildInterface` 和状态显示方法。视觉组件不得访问 Qwen、MemOS、日志或设置存储。

绘制要求：

- 所有 GDI 对象在使用后释放。
- 面板启用双缓冲，避免窗口缩放闪烁。
- 绘制只响应尺寸、主题和重绘事件，不启动计时器。
- 设计坐标按 DPI 和控件尺寸换算，不写死屏幕像素位置。

## 9. 文案

保留清晰、可操作的中文：

- 标题：`Qwen Local`
- 本地声明：`所有对话均在本机处理。`
- 初始消息：`正在检查本地 Qwen3.5-9B 服务；长期记忆和磁盘日志默认关闭。`
- 输入提示：`输入消息`
- 快捷键提示：`Enter 发送 · Shift+Enter 换行`
- 日志说明继续明确可见问答会写入 D 盘。

不使用“智能中枢”“无限能力”等抽象宣传文案。

## 10. 交互与无障碍

- 保留 `Enter` 发送、`Shift+Enter` 换行和 `AcceptButton`。
- 发送期间继续禁用发送按钮，避免并发请求。
- 控件继续提供中文 `AccessibleName`。
- 状态信息同时包含符号和文字，不能只靠灰阶差异。
- 文本和主要控件对比度以 WCAG AA 为最低目标。
- 键盘焦点使用 2px 浅色边框，不移除原生焦点提示而不给替代。
- 高 DPI 下检查 100%、125%、150% 缩放，不允许文字截断或操作栏重叠。

## 11. 设计自审

- 避免“黑成一片”：背景、主面板、输入区和边框至少使用四级灰阶层次。
- 避免装饰压过内容：柔光、星点和连线的亮度低于正文与控件边框，并避开主要文字区。
- 避免通用后台模板感：使用本地端口微标签、模型状态和固定粒子光带作为产品识别元素。
- 避免只靠颜色传达状态：每种状态都有符号和文字。
- 避免窄窗口挤压：小于 820px 时减少装饰并允许操作区重新排列。
- 空状态、加载、错误和正常聊天共享同一信息层级；错误提高文字亮度和符号强度，不改变整体色系。
- 不使用动画，系统“减少动态效果”设置无需额外分支。

## 12. 验证计划

### 12.1 自动化和静态验证

- 现有核心测试全部通过。
- 构建和单文件发布退出码为 0。
- 验证 EXE 包含图标资源，ICO 具有全部目标尺寸。
- 静态检查新增代码不包含外部 URL、网络素材或非 D 盘数据路径。
- 检查视觉组件不包含定时器、后台线程或业务服务引用。

### 12.2 真实窗口验证

- 在 100% 和一个高 DPI 缩放比例下启动窗口并截图。
- 检查初始尺寸和最小尺寸：标题、状态、对话区、输入区、两个开关和三个按钮均可见。
- 检查 3C 装饰可辨识：斜向柔光、星点和星图连线在深黑背景上可见，且不遮挡文字。
- 检查窗口缩放无明显闪烁、控件重叠或文字截断。
- 检查标题栏、任务栏和 EXE 文件均显示新图标。

### 12.3 功能回归

- 完成一次真实中文问答，验证模型服务复用且 PID 不增加。
- 验证 MemOS 与日志首次设置、运行时切换和持久化行为不变。
- 验证日志仍只写入可见问答，隐藏记忆不进入日志。
- 验证关闭窗口的模型进程所有权选择保持原行为。
- 验证监听仍为 `127.0.0.1:18135`，没有新增外部网络连接。

## 13. 验收标准

只有以下条件都有当前证据时，视觉刷新才算完成：

- 3C 粒子光带方向在真实 WinForms 窗口中清晰可辨。
- 黑白主题、图标和控件视觉统一。
- 最小尺寸和高 DPI 下布局可用。
- 原有自动化测试、真实聊天、MemOS、日志、模型复用和回环边界没有回归。
- 最终发布产物仍为 D 盘可双击启动的单文件 `QwenLocalChat.exe`。
